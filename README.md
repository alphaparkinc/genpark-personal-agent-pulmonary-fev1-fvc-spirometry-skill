## 🛠️ MCP Tools Exposed
- `calculate_tiffeneau_spirometry_index`: Compute FEV1/FVC percentage and identify airway obstruction or restriction patterns.
- `synthesize_respiratory_muscle_training_protocol`: Formulate inspiratory muscle training (IMT) resistance protocol to expand functional lung reserve.
